The biggest single jump yet. 22 upstream commits — including fixes for three issues this harness filed (#1256 module-body, #1257 Regexp.last_match, #1258 Float-in-Hash) plus Struct typing, alias, JSON.generate for records and more — moved 20,175 gems out of rejected, among them rspec, globalid, mini_portile2 and coffee-rails.

95557f5 → a782696 ↑ 17 graduated ↓ 21 regressed

A consolidation rev. The base verdict mix is essentially flat after the previous jump — 13 upstream commits of correctness fixes (StringScanner, Time#to_s, Dir.exist?/alias_method, and the RBS-extractor union→poly change) graduated a small set of gems — google-adwords-api, libdatadog, random_user_agent, twitter_username_extractor and the redcar-* cluster — while a couple regressed and were caught by the re-probe. The bigger story this rev was off the catalog: the harness found spinel_analyze consuming 100+ GB on a cluster of auto-generated API-SDK gems (a compiler memory blow-up, filed upstream).

Top transitions: clean->rejected 12 · rejected->clean 12 · risky->rejected 9 · rejected->risky 5

a782696 → 9c0a5f0 ↑ 3.9k graduated ↓ 386 regressed

The harness loop paying off. matz landed fixes for six issues this harness filed the day before — all common idioms: block_given? with a named &blk (#1316), inject(&:+) (#1317), reopening class Object (#1306), a stdlib class held in an instance variable (#1305), and a branch-assigned local inside a lambda/proc (#1315). 3,487 gems moved out of rejected (110.3k→106.8k). The one feature ruled out of scope — aliasing the regexp special globals (#1307) — now fails with a clear diagnostic instead of bad C.

Top transitions: rejected->clean 2.2k · rejected->risky 1.6k · clean->rejected 247 · risky->rejected 139

9c0a5f0 → 5c9790c ↑ 20 graduated ↓ 1 regressed

Typed-collection coverage. matz fixed three issues this harness filed hours earlier — all the same shape: a method that exists on the generic path but was missing on a specialized collection. Hash#fetch on an int→int hash (#1329), Array#join on a mixed poly_array (#1332), and a Class value stored in a Hash/Array now typed as poly instead of int (#1337, which had broken every options-hash carrying an exception class). The compile+scan base barely moves on fixes like these — they're full-surface/runtime, so the graduation shows in the behaviour-verified tier.

Top transitions: rejected->risky 10 · rejected->clean 10 · clean->rejected 1

5c9790c → 57af7f9 ↑ 87 graduated ↓ 31 regressed

The spine-gems wave. Auditing why bundler/rake/minitest/thor reject found two shallow front doors — alias to an attr_reader-generated method (#1356, rake + thor) and &:sym after a positional argument mis-parsed as a hash literal (#1359, bundler + minitest) — and matz closed both within a day, alongside 7 more harness filings. All four spine gems now compile past their old blockers into distinct second-tier issues (#1368 et al.). C compile errors now map back to Ruby source lines via #line, on by default — the #1338 RFC direction. The behaviour-verified tier reached 144 mechanical ★ this run.
